Spanish NIE, NIF, CIF and IBAN validator

Detects the type of identifier, checks its control letter or digit, and tells you what is wrong.

Calculated in your browser with the same code as the API: nothing you type is sent anywhere.

How it works

  • NIE (foreigner identity number): X, Y or Z, 7 digits and a control letter. NIF (DNI): 8 digits and the letter.
  • CIF (companies): a letter, 7 digits and a control character (digit or letter, depending on the entity).
  • IBAN of any country, with the check digits (mod 97) and the length for the most common countries.
  • It checks that the value is consistent, not that it exists or who owns it.

Validating form data?

The Validaciones ES API checks NIF, NIE, CIF, IBAN and postal codes, with the reason when one fails.
