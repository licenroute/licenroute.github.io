Agents can read the bill

Bots and AI agents get a 402 that names the plan, the price and the checkout link. They can pay instead of scraping.

How the 402 answer works

GET /api/reports, no key
HTTP/1.1 402 Payment Required
{
  "error": "payment_required",
  "payment": {
    "plan_id": "api-reports",
    "checkout_url": "https://example.com/plans/api-reports",
    "currency": "EUR",
    "unit_price_minor": 150,
    "unit_size": 1000
  }
}

What works today

In the free preview

  • Express 4 and 5, JavaScript or TypeScript
  • Setup with Claude Code or Cursor
  • Tests on your own machine
  • Exact undo
  • English and Spanish

Not yet

  • Real payments (the hosted service isn’t open)
  • Next.js, Supabase or Python
  • Production traffic
  • Windows

Tell us what you built

Before you paste it

Do I need to understand the code?

Not deeply. You read a short summary and approve it yourself, and your assistant can explain each step.

Will my login break?

No. Login, health checks and sign-up are never made paid, and the tests check that free pages still work.

Can I charge real money?

Not yet. The preview runs locally so you can test the whole flow. Real payments need the hosted service.
