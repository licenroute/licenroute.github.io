Un servidor MCP para el Market de LicenRoute

Gratis · sin dependencias · Node.js 20+ · Apache-2.0

Tu asistente de IA busca APIs en el Market, lee sus planes y la prueba gratis, y te da el enlace. Nunca paga ni guarda claves: abres tú el enlace y decides.

Conéctalo

Claude Code:

claude mcp add licenroute-market -- npx -y @licenroute/market-mcp

Claude Desktop, Cursor, Windsurf y otros clientes:

{
  "mcpServers": {
    "licenroute-market": {
      "command": "npx",
      "args": ["-y", "@licenroute/market-mcp"]
    }
  }
}

Sin npx: npm install -g @licenroute/market-mcp y usa licenroute-market-mcp como comando. El nombre lleva ámbito: @licenroute/market-mcp.

Pídeselo

  • Busca una API de festivos de España y dame el enlace de la prueba gratis.
  • ¿Hay alguna API para validar NIF y CIF? ¿Cuánto cuesta?
  • Necesito calcular el IVA y la retención de IRPF de mis facturas. ¿Qué hay en el Market?

Herramientas

HerramientaQué hace
search_apisBusca en el Market en español o en inglés. Devuelve cada API con su plan más barato y si tiene prueba gratis.
get_apiTodos los detalles de una API: descripción, documentación, ejemplo, uso real de los últimos 30 días y todos sus planes.
request_purchaseEl enlace donde una persona empieza la prueba gratis o compra un plan. La herramienta no paga nada.

Qué hay en el Market

Festivos (España y más de 100 países), validación de IBAN, NIF, NIE y CIF, cálculo de IVA y retención de IRPF en facturas, importes en letra, municipios y códigos postales de España, comprobación de teléfonos y correos, y códigos QR. Todas las APIs tienen una prueba gratis de 100 peticiones; los packs de 10.000 peticiones empiezan en 5 €.

Seguro por diseño

  • Las tres herramientas son de solo lectura.
  • Solo habla con la dirección del Market que configures (https) y descarta cualquier enlace que apunte a otro sitio.
  • Durante el piloto, los pagos siguen en modo de pruebas de Stripe.
