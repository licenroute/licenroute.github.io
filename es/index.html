Developer preview · modo demo · código abierto (Apache-2.0)

Cobra por las rutas de tu API Express que lo valen.

LicenRoute pone licencias, cuotas de uso y revocación delante de las rutas que elijas (informes, datos, exportaciones) mientras el login, las páginas públicas y los health checks siguen exactamente igual. Lo integras tú o tu asistente de IA en minutos. Nada se escribe hasta que una persona lo aprueba.

Pruébalo en 5 minutos Ver en GitHub

Sin cuenta y sin Docker. Funciona en local contra un simulador: no se cobra nada.

El problema

Tu API es todo o nada

Algunas de tus rutas valen dinero. Hoy, o son públicas (cualquiera las rastrea, también los crawlers de IA) o están detrás de tu propio login. Construir claves de API, cuotas, medición y revocación lleva semanas, y un error en el middleware o bloquea a tus usuarios o lo regala todo.

Acceso de pago por ruta

Vende un paquete de peticiones a /api/informes/** sin tocar /login ni /health.

Licencias revocables

Una clave inventada recibe 403. Revocas una y la siguiente petición se rechaza, sin redesplegar.

Seguro cuando algo falla

Si el servicio de decisiones cae, las rutas de pago se cierran (503) y las públicas siguen. Nada se sirve gratis por accidente.

Cómo funciona

De tu código a rutas de pago en cuatro pasos

La CLI lee tu app Express sin ejecutarla, propone qué proteger y solo escribe el cambio exacto que aprobó una persona.

1

Detecta

Análisis estático de Express 4/5: JS o TS, ESM o CommonJS, routers montados con app.use. Encuentra health checks, login, rutas públicas y rutas ya autenticadas.

2

Planifica

Planes por prefijo de ruta y método HTTP (GET+HEAD; OPTIONS nunca se cobra). Nunca propone login, health checks ni escrituras: te los lista para que decidas.

3

Aprueba

Ves el diff completo. Para escribirlo, una persona teclea un reto de un solo uso en su terminal. El modelo de permisos de Node es una segunda barrera.

4

Prueba y deshaz

licenroute test comprueba cada caso contra un simulador local. licenroute undo restaura tus ficheros byte a byte.

Pensado para la IA

Hecho para que lo integren asistentes de IA y lo consuman agentes de IA

Tu asistente prepara, tú apruebas

Ejecuta licenroute assistant . --claude-code (o --cursor) para instalar una Skill o reglas que enseñan el flujo seguro detectar → planificar → previsualizar → tu aprobación → probar → deshacer, y un hook que:

  • te pregunta antes de cualquier escritura de LicenRoute
  • impide al asistente leer ficheros .env*
  • deniega atajos de aprobación y ejecutores como npx

El asistente puede hacerlo todo menos teclear el reto: la CLI lo pide en tu terminal.

Los agentes reciben una respuesta legible por máquinas

Un programa que llama sin licencia a una ruta protegida no recibe una página de error, sino un JSON que le dice cómo desbloquearla:

Pruébalo

Míralo funcionar sobre la API de ejemplo en 5 minutos

Necesitas Node.js 24+, npm y git (y script de util-linux en Linux). Sin cuenta y sin Docker.

git clone https://github.com/licenroute/licenroute.git licenroute && cd licenroute
npm ci --ignore-scripts      # dependencias de desarrollo del registro público de npm
npm run build                # construye los paquetes de la CLI y el SDK + SHA256SUMS
./demo/demo.sh               # solo lectura: enseña los planes y el diff exacto

Después sigue el tutorial de 10 minutos para aprobar la integración, arrancar el simulador y ejecutar licenroute test. ¿Prefieres paquetes ya construidos? Descárgalos de la release v0.3.1-preview y compruébalos con SHA256SUMS.

No ejecutes nunca npx licenroute. Los paquetes no están publicados en npm y el nombre sin ámbito de allí no es este proyecto. Instala solo los .tgz que construiste o verificaste.

Estado, con honestidad

Qué funciona hoy y qué todavía no

Funciona en la preview

  • Express 4 y 5, JS y TS, ESM y CommonJS
  • Análisis estático, planes por ruta y método
  • Aprobación ligada al diff exacto y undo exacto
  • Simulador local: licencias, cuotas, revocación, caída y recuperación
  • Integración con Claude Code y Cursor; inglés y español
  • Validado en macOS (Apple silicon) y Ubuntu 24.04 x86_64

Todavía no

  • Sin servicio alojado: ni licencias reales, ni facturación, ni pagos
  • Sin revisión para tráfico de producción ni auditoría de seguridad externa
  • No está en npm (los nombres bajo @licenroute son provisionales)
  • Rails se analiza pero no se integra; Windows sin probar

Preguntas

Lo que preguntan los desarrolladores

¿Cómo añado claves de API y cuotas a una API Express que ya tengo?

Instala la CLI y el SDK de Express desde los paquetes verificados, ejecuta ./node_modules/.bin/licenroute init . para ver los planes, previsualiza el diff con --plans y apruébalo con --write --approve apr_… y el reto tecleado en tu terminal. El tutorial lo explica paso a paso.

¿Puedo vender el uso por paquetes de peticiones?

Sí, ese es el modelo: cada plan tiene una cuota (por ejemplo, 1000 peticiones) y un precio por paquete. GET y HEAD comparten cuota; OPTIONS nunca se cobra. En la preview todo va contra el simulador, así que no se cobra nada de verdad.

¿Es seguro que lo integre un asistente de IA?

Para eso está diseñado. El asistente detecta, planifica, previsualiza y prueba, pero escribir exige que una persona teclee un reto en su terminal. El hook incluido también le impide leer ficheros .env y usar atajos de aprobación. El reto prueba que alguien lo tecleó allí, no quién.

¿Qué pasa con mi login, mis health checks y mis páginas públicas?

Nunca se proponen para licencias. LicenRoute los lista como «no se tocan» o «requieren tu decisión», y licenroute test comprueba que las rutas públicas siguen respondiendo 200.

¿Y si el servicio de licencias está caído?

Las rutas con licencia se cierran con 503 (también si tu app arranca con el servicio inaccesible) y las públicas siguen funcionando. Las pruebas simulan la caída y la recuperación.

¿En qué se diferencia de un API gateway o de un rate limiter?

LicenRoute vive dentro de tu app Express como middleware, declarado por ruta y método HTTP, así que un POST con su propia autenticación bajo el mismo prefijo no se toca. Vende y aplica licencias con cuota; no es un proxy delante de toda tu API.

¿Está listo para producción? ¿Hay servicio alojado?

No, y todavía no. Es una developer preview en modo demo. Si usarías una versión alojada que emita licencias reales y gestione los pagos, cuéntanos qué necesitas.

¿Tienes una API Express con rutas que valen dinero?

Prueba la preview y dinos qué falta. El servicio alojado es el siguiente paso si los desarrolladores lo necesitan.
