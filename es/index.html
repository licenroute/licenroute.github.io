Con palabras sencillas

Qué cambia en tu app

Tú eliges qué es de pago, por ejemplo tus informes o tus datos. Todo lo demás sigue gratis: el registro, el login, tu página de inicio.

Por qué es seguro con IA

Tu asistente hace el trabajo. Tú tienes la llave.

No puede aprobarse a sí mismo

Escribir en tu código exige un código tecleado por una persona en el terminal. Ningún ajuste, atajo ni prompt se lo salta.

No puede leer tus secretos

Un complemento opcional para Claude Code y Cursor impide al asistente abrir tus ficheros .env y ejecutar paquetes desconocidos.

Los agentes de IA entienden la respuesta

Cuando un bot o un agente de IA llega a una parte de pago, la respuesta «paga primero» se puede leer por máquina: plan, precio y dónde comprar. Pueden pagar en vez de rastrear.

Verlo funcionar

Pruébalo con una app de ejemplo en 5 minutos

No necesitas una app propia. Necesitas Node.js 24 o superior, npm y git. Sin cuenta y sin Docker. O pídele a tu asistente que lo haga contigo.

git clone https://github.com/licenroute/licenroute.git licenroute && cd licenroute
npm ci --ignore-scripts
npm run build
./demo/demo.sh          # enseña lo que cambiaría, sin cambiar nada

Después sigue el tutorial de 10 minutos para aprobarlo y lanzar las pruebas tú mismo.

No ejecutes nunca npx licenroute. LicenRoute todavía no está en npm, y un paquete con ese nombre allí no es este proyecto. Tu asistente lo sabe si lee llms.txt.

Estado, con honestidad

Qué puedes hacer hoy y qué viene

Hoy (preview gratuita)

  • Convertir en de pago partes de una API Express, con claves y límites de uso
  • Probar todo el flujo en tu ordenador: paga primero, entra, se agota, se revoca
  • Dejar que Claude Code o Cursor lo configuren, con tu aprobación
  • Deshacerlo por completo
  • Inglés y español; macOS y Linux

Todavía no

  • Cobrar dinero real: necesita el servicio alojado, que no está abierto
  • Next.js, Supabase, Python, Rails u otros frameworks
  • Usarlo en producción con clientes reales
  • Windows (sin probar)

Preguntas

Preguntas frecuentes

Hice mi app con IA. ¿De verdad puedo usar esto?

Si tu backend es una app Node.js con Express (pregúntale a tu asistente: «¿mi backend usa Express?»), sí. Pega el prompt y tu asistente hace la configuración. Tú lees el resumen y lo apruebas en tu terminal.

¿Necesito entender el código?

No a fondo. LicenRoute te enseña un resumen de lo que va a cambiar y tu asistente te lo puede explicar. Lo que no te puedes saltar es aprobarlo tú: eso es lo que mantiene segura tu app.

¿Puedo cobrar dinero real hoy?

No. La preview funciona en modo demo en tu ordenador, para que lo pruebes todo sin riesgo. Las claves reales y los pagos necesitan el servicio alojado, que todavía no está abierto. Si lo usarías, cuéntanoslo.

¿Romperá mi login o mis páginas gratis?

No. LicenRoute nunca propone hacer de pago el login, los health checks ni el registro. Te los lista para que veas que siguen gratis, y sus pruebas comprueban que las páginas gratis siguen funcionando.

¿Y si LicenRoute se cae?

Las partes de pago se cierran (nadie entra gratis) y las gratis siguen funcionando. Las pruebas simulan justo eso.

¿Cuesta algo?

La preview es gratis y de código abierto (Apache-2.0).

Para desarrolladores

Los detalles técnicos

Qué es

Una CLI y un middleware para Express 4/5. La CLI analiza tu app de forma estática (nunca la ejecuta), propone planes por prefijo de ruta y método HTTP (GET+HEAD comparten cuota, OPTIONS nunca se cobra) y solo escribe el diff ligado a un código de aprobación más un reto tecleado en /dev/tty. El modelo de permisos de Node es una segunda barrera.

Qué reciben los clientes

Sin licencia: 402 con {"error":"payment_required","payment":{"plan_id","checkout_url","currency","unit_price_minor","unit_size"}}. Las licencias van en Authorization: Bearer bgat_…. Las rutas de pago se cierran (503) si el servicio de decisiones no responde, también al arrancar.

Paquetes

@licenroute/cli 0.3.1 y @licenroute/connect-express 0.8.0, construidos desde el código o descargados de la release y verificados con SHA256SUMS. Node.js 24+ para la CLI, 20+ para el SDK.
