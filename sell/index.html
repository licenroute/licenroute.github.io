Charge the users you already have.

Your API is useful and people already call it for free. LicenRoute puts a paid lane in front of the routes you choose, without touching the free ones.

Create an account

Free and open source. Express 4/5 on Node.js 22.13+. No marketplace needed.

Is this for you?

  • You built an API (by hand or with Claude Code or Cursor) and people, apps or AI agents already use it.
  • You give it away because building keys, quotas and billing is a week of boring work.
  • You want to charge for the valuable part and keep the rest free.

Live this week, in four steps

1 · Paste the prompt

Your assistant reads your code and proposes which routes to charge for. Login, health checks and writes stay free.

2 · Approve the change yourself

You see the exact diff and type a one-time code in your own terminal. Your assistant can never approve its own change, and licenroute undo restores your code exactly.

3 · Try it with fake money

A local simulator answers like the real service: licenroute test checks 402 without a key, 200 with one, quotas, revocation and that free routes still work.

4 · Turn it on

Create an account, set your packs (for example 10,000 requests for 30 days) and a free trial, and issue keys to your customers. List the API in the Market if you want more buyers.

What you get

Keys per customer

Revocable in one click, no redeploy.

Usage packs

Requests per period, counted atomically; when the pack runs out the answer is 402 again.

A free trial

100 requests by default, issued automatically.

An answer AI agents understand

HTTP 402 with the plan, price and where to buy, in JSON.

Free routes untouched

If LicenRoute is unreachable, paid routes close (503) and free ones keep working.

Optional shop window

A Market listing, a catalogue for agents and an MCP server that finds your API.

How you get paid today

By Bizum or bank transfer, coordinated by email. A buyer requests a pack and picks how to pay; you get an email with their address, the amount and a reference; you send your payment details; when the money arrives you register it and the buyer collects their key, which you never see. The money goes straight to you.

Card payments with Stripe come after a security review. During the pilot LicenRoute charges sellers no fee. You issue your own invoices.

Not yet

  • Frameworks other than Express (Next.js, Supabase, Python)
  • Card payments
  • Uptime guarantees (it is a pilot)
  • Windows

Questions sellers ask

Do I need the Market?

No. LicenRoute is for charging the users you already have. The Market is an optional extra shop window.

Does my traffic go through LicenRoute?

No. Your responses never pass through it: the middleware only asks whether a key is valid and counts one unit of usage.

What if I want to leave?

Run licenroute undo: your code goes back exactly as it was. The CLI and middleware are open source (Apache-2.0).

What does it cost?

The tools are free. The hosted pilot charges sellers no fee for now; we will announce any fee well in advance.
