An MCP server for the LicenRoute Market

Free · zero dependencies · Node.js 20+ · Apache-2.0

Your AI assistant searches the Market for APIs, reads their plans and the free trial, and gives you the link. It never pays and never holds a key: you open the link and decide.

Connect it

Claude Code:

claude mcp add licenroute-market -- npx -y @licenroute/market-mcp

Claude Desktop, Cursor, Windsurf and other clients:

{
  "mcpServers": {
    "licenroute-market": {
      "command": "npx",
      "args": ["-y", "@licenroute/market-mcp"]
    }
  }
}

Without npx: npm install -g @licenroute/market-mcp, then use licenroute-market-mcp as the command. The name is scoped: @licenroute/market-mcp.

Ask it

  • Find an API for Spanish public holidays and give me the link to the free trial.
  • Is there an API to validate IBANs? How much does it cost?
  • I need to generate QR codes from my backend. What does the Market have?

Tools

ToolWhat it does
search_apisSearches the Market in English or Spanish. Returns each API with its cheapest plan and whether it has a free trial.
get_apiFull details of one API: description, docs, example, real usage in the last 30 days and every plan.
request_purchaseThe link where a person starts the free trial or buys a plan. Nothing is paid by the tool.

What is in the Market

Public holidays (Spain and 100+ countries), IBAN, NIF, NIE and CIF validation, Spanish VAT and IRPF invoice maths, amounts in words, Spanish municipalities and postal codes, phone and email checks, and QR codes. Every API has a free trial of 100 requests; packs of 10,000 requests start at 5.

Safe by design

  • All three tools are read-only.
  • It only talks to the Market address you configure (https) and drops any link that points elsewhere.
  • Payments stay in Stripe test mode during the pilot.

Source on GitHub · package on npm · listed in the official MCP registry as io.github.licenroute/market-mcp.

Have an API of your own? LicenRoute adds a paid lane to it and lists it in the Market, where this server finds it.
